## 🧑‍💻 DevOps Interview Focus

While studying each service, focus on:

### 1. Fundamentals

Understand **what the service is and why it is used**.

### 2. Architecture

Know how the service interacts with other AWS services.

### 3. Hands-on

Actually create, configure, monitor, and troubleshoot the service.

### 4. CLI

Learn the important AWS CLI commands.

### 5. Security

Understand IAM permissions, encryption, networking, and access control.

### 6. Troubleshooting

Practice production-style problems instead of memorizing definitions.

### 7. Scenario Questions

Prepare for questions such as:

> "Your EC2 instance is running but the application is not accessible. How would you troubleshoot it?"
